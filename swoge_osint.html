What can you learn about this?

Paste a domain, an IP, a website or an on-chain address and it fans out across public sources — DNS, registry, certificate logs, the site's own pages, launchpad records. An e-mail, a username or a phone number is checked as a selector: what is publicly known about it, never expanded into a person. Every line carries the source it came from.
Machines and accounts, not people.
You start from a domain, an IP, a website or an on-chain address. A person's name is not a starting point — with lawful sources a name search returns nothing, and what makes it work elsewhere (data brokers, leaked databases) is exactly what this tool does not query. A person appears below only when an organisation published them on its own page.
